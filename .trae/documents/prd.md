## 1. 产品概述

这是一个面向个人用户的英语学习网页应用，旨在提供沉浸式、高效的英语学习体验。通过整合单词记忆、听力训练和阅读理解三大核心功能，帮助用户系统性地提升英语能力。

- **目标用户**：个人英语学习者，希望通过系统化练习提升词汇量、听力水平和阅读能力
- **核心价值**：一站式英语学习平台，简洁高效，数据本地存储保护隐私

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册 | 使用所有学习功能，管理个人学习数据 |

### 2.2 功能模块

1. **首页**：导航入口、学习进度概览、每日学习统计
2. **单词本**：单词列表、添加/编辑单词、单词卡片翻转、记忆测试
3. **听力训练**：音频播放器、录音列表、听力笔记
4. **阅读理解**：文章列表、阅读界面、生词标注、理解测试

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 学习进度卡片 | 显示今日已学单词数、听力时长、阅读篇数 |
| 首页 | 快捷入口 | 三个功能模块的快捷导航按钮 |
| 首页 | 学习日历 | 热力图展示学习打卡记录 |
| 单词本 | 单词列表 | 展示所有单词，支持搜索和筛选 |
| 单词本 | 单词卡片 | 点击翻转显示释义，标记已掌握/未掌握 |
| 单词本 | 添加单词 | 表单输入单词、音标、释义、例句 |
| 单词本 | 记忆测试 | 随机抽取单词进行测试，显示正确率 |
| 听力训练 | 录音列表 | 展示所有录音文件，支持分类筛选 |
| 听力训练 | 音频播放器 | 播放/暂停、进度条、倍速调节、循环播放 |
| 听力训练 | 听力笔记 | 边听边记，支持时间戳标记 |

| 阅读理解 | 阅读界面 | 文章内容展示，支持字体大小调节 |
| 阅读理解 | 生词标注 | 点击单词添加到生词本，高亮显示 |
| 阅读理解 | 理解测试 | 阅读后答题，显示得分和解析 |

## 3. 核心流程

### 3.1 单词学习流程

用户进入单词本 → 浏览单词列表或添加新单词 → 点击单词卡片翻转查看释义 → 标记掌握状态 → 进入记忆测试模式 → 完成测试查看正确率

### 3.2 听力训练流程

用户进入听力训练 → 选择录音文件 → 播放音频 → 调节播放速度 → 边听边记笔记 → 完成听力练习

### 3.3 阅读理解流程

用户进入阅读理解 → 选择文章 → 阅读文章内容 → 点击生词添加到单词本 → 完成阅读后答题 → 查看得分和解析

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝色 (#1a365d) 作为主色，搭配温暖的琥珀色 (#f59e0b) 作为强调色
- **辅助色**：柔和的灰色系用于背景和边框，白色用于卡片背景
- **按钮风格**：圆角按钮，带有轻微阴影和悬停动画效果
- **字体**：
  - 标题字体：Playfair Display（优雅的衬线字体，适合学习氛围）
  - 正文字体：Source Sans Pro（清晰易读的无衬线字体）
- **布局风格**：卡片式布局，左侧固定导航栏，右侧内容区域
- **图标风格**：线性图标，简洁现代

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 学习进度卡片 | 白色卡片背景，圆角12px，轻微阴影，进度条动画 |
| 首页 | 快捷入口 | 三个彩色图标按钮，悬停放大效果，渐变背景 |
| 首页 | 学习日历 | 热力图样式，深浅不一的蓝色方块，悬停显示日期 |
| 单词本 | 单词列表 | 网格布局，每个单词卡片可翻转，正面英文背面中文 |
| 单词本 | 添加单词 | 模态框表单，输入框带图标，提交按钮渐变色 |
| 单词本 | 记忆测试 | 全屏测试模式，选项卡片，正确/错误动画反馈 |
| 听力训练 | 录音列表 | 列表布局，每项显示标题、时长、分类标签 |
| 听力训练 | 音频播放器 | 底部固定播放器，波形进度条，圆形播放按钮 |
| 听力训练 | 听力笔记 | 侧边笔记面板，支持富文本，时间戳可点击跳转 |
| 阅读理解 | 文章列表 | 卡片列表，显示难度星级、字数、预计阅读时间 |
| 阅读理解 | 阅读界面 | 居中排版，舒适的行高和字间距，生词高亮下划线 |
| 阅读理解 | 理解测试 | 弹出式答题面板，单选题卡片，进度指示器 |

### 4.3 响应式设计

- **桌面优先**：主要针对桌面端设计，充分利用大屏幕空间
- **平板适配**：导航栏可折叠为汉堡菜单，卡片布局自适应
- **移动端适配**：单列布局，底部导航栏，触摸友好的交互元素

### 4.4 动效设计

- **页面切换**：淡入淡出效果，持续时间300ms
- **卡片翻转**：3D翻转动画，持续时间500ms
- **按钮交互**：悬停时轻微上浮和阴影加深
- **进度条**：平滑过渡动画，持续时间800ms
- **列表加载**：交错淡入效果，每个项目延迟100ms
